# Open-Source README Design

**Date:** 2026-08-13  
**Author credit:** Gokul Ravi (`GokulRavi1`)  
**License:** MIT

## Decisions

- Audience: open-source users / developers (docs-first)
- Use cases: creative / professional only
- Experiment succession: narrative Phase 0→6 inside README (no fake metrics)
- Docs: Classic OSS README + `docs/ARCHITECTURE.md` only (no separate RESEARCH.md)
- Visuals: shields.io badges, emoji headers, Mermaid diagrams

## Deliverables

1. `README.md` — about, features, use cases, architecture preview, quick start, API, experiment succession, requirements, contributing, author, license
2. `LICENSE` — MIT, Copyright (c) 2026 Gokul Ravi
3. `docs/ARCHITECTURE.md` — stack, service map, data flow, project tree

## Out of scope

- Binary logo assets
- Separate research markdown
- Adult/NSFW use-case framing
